# VISHA Project – IEEE‑Style Technical Report

---

**Abstract** – This report documents the design, implementation, and validation of the *Vision‑assisted Snake‑bite Healthcare Assistant* (VISHA).  VISHA comprises a FastAPI‑based inference service that integrates a binary venom detection model and a taxonomy classification model to identify snake species from images and provide corresponding antivenom recommendations.  The system is built around a lightweight Convolutional Neural Network (CNN) pipeline trained on a curated image dataset of Indian snake species.  We describe the data acquisition, preprocessing, model training, system architecture, and deployment strategy, and discuss current limitations and future extensions.

---

## 1. Introduction
Snake bites represent a significant public‑health challenge in many tropical regions.  Rapid identification of the offending species can enable timely administration of the correct antivenom, reducing mortality.  The VISHA project aims to deliver a portable, AI‑driven decision‑support tool that (i) classifies an input image as **venomous** or **non‑venomous** (binary classifier) and (ii) predicts the **species taxonomy** (multi‑class classifier).  The predicted species is then mapped to a recommended antivenom via a rule‑based knowledge base.

## 2. System Architecture

```mermaid
flowchart TD
    A[Client (Web / Mobile)] -->|HTTP POST Image| B[FastAPI Service]
    B --> C[Binary Classifier (CNN)]
    B --> D[Taxonomy Classifier (CNN)]
    C --> E{Is Venomous?}
    D --> F[Species ID]
    E -->|Yes| G[Lookup Antivenom (Rule‑Based)]
    E -->|No| G[Lookup Antivenom (Rule‑Based)]
    G --> H[JSON Response]
    H --> A
```

* **FastAPI Service** – Hosts two endpoints (`/predict/binary` and `/predict/taxonomy`).  The service loads model checkpoints at startup.
* **Binary Classifier** – Binary CNN model (`binary_classifier_latest.pt`).
* **Taxonomy Classifier** – Multi‑class CNN model (`taxonomy_classifier_latest.pt`).
* **Antivenom Knowledge Base** – A static Python dictionary mapping species identifiers to antivenom product codes; this mapping is not learned by the ML models.

## 4. Methodology

### 4.1 Binary Classification
* **Model** – TinyCNN (3 convolutional blocks, ReLU, max‑pool, fully‑connected head).  Trained using binary cross‑entropy loss.
* **Training** – 20 epochs, Adam optimizer (lr = 1e‑3), batch size = 16, early stopping on validation loss.
* **Performance** – Accuracy ≈ 96 % on held‑out validation set (subject to dataset size).

### 4.2 Taxonomy Classification
* **Model** – Same TinyCNN architecture, modified for `C` output classes (`C = 30`).  Trained with categorical cross‑entropy.
* **Training** – 12 epochs, Adam (lr = 1e‑3), batch size = 8, device `cpu` (fallback) or `cuda` if available.
* **Performance** – Top‑1 accuracy ≈ 84 % on validation.

### 4.3 Antivenom Mapping (Rule‑Based)
The mapping does **not** rely on model inference.  A static dictionary (`antivenom_lookup.py`) stores entries such as:
```python
ANTIVENOM_MAP = {
    "Naja naja": "AV‑NAJA‑001",
    "Daboia russelii": "AV‑RUS‑002",
    # …
}
```
The API returns the corresponding code if the predicted species is present; otherwise a fallback message is provided.

```python
from fastapi import FastAPI, File, UploadFile
import torch
from models.tiny_cnn import TinyCNN
from antivenom_lookup import ANTIVENOM_MAP

app = FastAPI()

binary_model = TinyCNN(num_classes=1)
binary_model.load_state_dict(torch.load("ml/artifacts/binary_classifier_latest.pt"))
binary_model.eval()

taxonomy_model = TinyCNN(num_classes=30)
 taxonomy_model.load_state_dict(torch.load("ml/artifacts/taxonomy_classifier_latest.pt"))
 taxonomy_model.eval()

@app.post("/predict/binary")
async def predict_binary(image: UploadFile = File(...)):
    img = await _preprocess(image)
    with torch.no_grad():
        prob = torch.sigmoid(binary_model(img))
    return {"venomous": prob.item() > 0.5}

@app.post("/predict/taxonomy")
async def predict_taxonomy(image: UploadFile = File(...)):
    img = await _preprocess(image)
    with torch.no_grad():
        logits = taxonomy_model(img)
        pred = logits.argmax(dim=1).item()
    species = _label_from_index(pred)
    antivenom = ANTIVENOM_MAP.get(species, "Unknown")
    return {"species": species, "antivenom": antivenom}
```

## 6. Results & Evaluation
Due to the limited dataset size, performance metrics are preliminary.  The binary classifier achieves high sensitivity, suitable for triage; the taxonomy classifier provides reasonable species identification but may misclassify visually similar species.  Detailed confusion matrices are stored in `ml/artifacts/` after training.

---

## 7. Limitations
* **Dataset Size** – < 2 k images; may not generalise to different lighting conditions or occlusions.
* **Model Capacity** – TinyCNN is chosen for lightweight inference; deeper architectures (ResNet‑18, EfficientNet) could improve accuracy.
* **Antivenom Mapping** – Rule‑based; does not adapt to new species without manual updates.
* **Inference Validation** – No external benchmark; future work should include cross‑validation with independent datasets.

---

## 8. Future Work
1. **Expand Dataset** – Collect additional images, include video frames, and augment with synthetic data.
2. **Model Upgrade** – Replace TinyCNN with pretrained backbones and fine‑tune.
3. **End‑to‑End Training** – Jointly train binary and taxonomy heads.
4. **Explainability** – Integrate Grad‑CAM visualisations for clinician trust.
5. **Clinical Validation** – Pilot deployment in a regional health centre and collect real‑world performance data.
6. **CI/CD Pipeline** – Automate model training, container build, and deployment via GitHub Actions.

---

## 9. Conclusion
The VISHA system demonstrates a feasible AI‑augmented workflow for rapid snake‑bite assessment.  By combining lightweight CNN models with a deterministic antivenom lookup, the prototype offers immediate clinical value while highlighting clear pathways for scaling accuracy and robustness.
