# VISHA – Symptom → Toxin → Antivenom Platform

**VISHA** (Vision‑Integrated Snake‑handling Assistant) is a lightweight Python project that demonstrates a complete end‑to‑end pipeline for:

1. **Clinical reasoning** – symptom → toxin → antivenom logic (hard‑coded knowledge base).
2. **Image‑based snake identification** – a binary classifier (snake vs. not‑snake) and a taxonomy classifier that predicts the snake species from images you provide.
3. **FastAPI service** – REST endpoints for health checks, model status, and placeholder prediction APIs.

The repository contains a minimal, self‑contained version that works entirely on a local Windows machine (no external Kaggle data required). All required images are already in the `archive/Snake Images` folder.

## 📂 Repository Layout

```

```

*The virtual environment (`.venv`) and the large image archive are deliberately **not** tracked in Git (see `.gitignore`).*

## 🚀 Quick Start Guide

### 1️⃣ Clone the repository (or pull the latest changes)
```powershell
git clone https://github.com/SwastikSenSharma2/HealthCare_AI-Ml_Mini_Project.git
cd HealthCare_AI-Ml_Mini_Project
```

### 2️⃣ Create and activate a virtual environment
```powershell
# From the project root
python -m venv .venv
& '.\.venv\Scripts\activate.ps1'
```
If you see the `(.venv)` prefix in your prompt, you are inside the environment.

### 3️⃣ Install Python dependencies
```powershell
pip install --upgrade pip
pip install fastapi uvicorn[standard] torch torchvision pandas python-dotenv pillow
```
> The `uvicorn[standard]` package includes `watchfiles` for `--reload` support.

### 4️⃣ (Optional) Train the taxonomy classifier
The repository ships a **tiny CNN** that can be trained in a few seconds for demo purposes.
```powershell
& '.\.venv\Scripts\python.exe' '.\ml\scripts\train_taxonomy_classifier.py' \
    --manifest '.\ml\data\manifests\india_taxonomy_images.csv' \
    --binary-checkpoint '.\ml\artifacts\binary_classifier_latest.pt' \
    --epochs 2 \
    --batch-size 4 \
    --device cpu
```
When training finishes you will see a line like:
```
Best checkpoint saved to ml\runs\taxonomy_2_4\best_model.pt
Training finished.
```
Copy that checkpoint to the location expected by the API:
```powershell
Copy-Item -Path ".\ml\runs\taxonomy_2_4\best_model.pt" \
          -Destination ".\ml\artifacts\taxonomy_classifier_latest.pt" -Force
```
The `.env` file already points to `ml/artifacts/taxonomy_classifier_latest.pt`; you can edit it if you store the checkpoint elsewhere.

### 5️⃣ Start the FastAPI server
```powershell
& '.\.venv\Scripts\python.exe' -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
You should see:
```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```
Open a browser and navigate to `http://localhost:8000/` – you will get a simple JSON greeting.

## 📚 API Endpoints
| Method | URL | Description |
|--------|-----|-------------|
| `GET` | `/` | Health check – returns `{ "message": "VISHA platform is up" }` |
| `GET` | `/health` | Returns `{ "status": "ok" }` |
| `GET` | `/api/v1/ml-inference/status` | Shows which models are loaded (binary always, taxonomy only after training). |
| `POST` | `/api/v1/ml-inference/predict/binary` | Placeholder endpoint – in a full implementation you would upload an image and get a *snake / not‑snake* prediction. |
| `POST` | `/api/v1/ml-inference/predict/taxonomy` | Placeholder – returns a taxonomy prediction **only if** the taxonomy checkpoint exists; otherwise returns HTTP 400. |

You can test them with `curl`:
```powershell
curl http://localhost:8000/health
curl http://localhost:8000/api/v1/ml-inference/status
```

## 📂 Data & Models
- **Image data**: All snake images you supplied are under `archive/Snake Images/`. They are *not* tracked by Git (see `.gitignore`).
- **Binary classifier checkpoint**: `ml/artifacts/binary_classifier_latest.pt` is included in the repo and works out‑of‑the‑box.
- **Taxonomy checkpoint**: Generated by the training script above; stored at `ml/artifacts/taxonomy_classifier_latest.pt`. If you skip training, the taxonomy endpoint will return a 400 error.
